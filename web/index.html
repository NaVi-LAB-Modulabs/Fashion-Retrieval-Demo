METHOD REFERENCE

Retrieval & scoring

  1. Parse the query

    An LLM extracts garment categories, positive and excluded attributes, directly named attributes, a positive visual description, and requested style targets.

  2. Select candidates

    The existing description vector index and required attribute edges supply separate candidate pools. A named category limits both pools. Candidate IDs are combined before fetching graph evidence.

  3. Filter and rank

    Directly named attributes, such as white in “white jacket”, require a matching graph edge and are the only attributes used in the graph score. Excluded attributes remove matching items. Inferred attributes are not used for graph candidate selection or scoring. Matching edges must meet the chosen confidence threshold. The final score is a weighted mean of available description similarity (55%), graph attribute match (35%), and requested style axes (10%).

Unavailable components are omitted and remaining weights are normalized. Candidate counts refer to fetched candidates before final filtering. Scores are retrieval signals, not probabilities.
