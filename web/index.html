METHOD REFERENCE

Retrieval & scoring

  1. Parse the query

    An LLM maps the query to garment types, required and excluded attributes, a semantic description, and style-axis targets.

  2. Retrieve graph candidates

    Parameterized Cypher applies the extracted constraints in Neo4j. The graph score averages the matched attribute edge scores. Minimum edge confidence filters the required attribute edges.

  3. Rerank available candidates

    Semantic similarity uses cosine similarity scaled to [0, 1]. A style-axis score is 1 − |item value − target|, averaged across available requested axes. The final score averages all active, available graph, semantic and style components.

Missing or inactive components are N/A, not zero. With no active components, the final score falls back to the graph score. Candidate counts refer to the fetched, limited pool. Scores are retrieval signals, not probabilities.
